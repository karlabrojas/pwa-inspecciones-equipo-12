# Modelo de amenazas y seguridad

## Alcance y supuestos

Este modelo describe la versión actual de la PWA de inspecciones de mantenimiento: interfaz Next.js, Service Worker, almacenamiento IndexedDB, cola de sincronización y la ruta demostrativa `/api/inspections`. El caso de uso es registrar observaciones de laboratorios y consultar su seguimiento, incluso durante interrupciones de conectividad.

El entorno actual es académico y usa datos de ejemplo que el proyecto considera sintéticos. No se presupone que la aplicación esté lista para producción ni que existan autenticación, autorización, cifrado de datos en reposo, gestión de sesiones, protección contra abuso o un servidor persistente. El modelo no sustituye un análisis institucional, legal ni una evaluación de impacto.

**Regla de datos:** no introducir datos personales reales, secretos, credenciales, fotografías ni información institucional no pública en código, pruebas, capturas, navegadores o despliegues de demostración. En `src/lib/data/inspections.ts` existen nombres e identificadores de apariencia realista como fixtures; el equipo debe confirmar que son ficticios y sustituir cualquier valor dudoso por valores manifiestamente sintéticos antes de publicar la aplicación. Esta revisión no puede certificar su origen.

## Límites de confianza y flujo de datos

1. **Formulario y renderizado de la aplicación:** los valores de título, laboratorio, responsable y resumen los proporciona el usuario del navegador. La UI React los representa como texto; no hay una ruta de renderizado HTML arbitrario en las vistas inspeccionadas.
2. **Origen de la PWA y almacenamiento del navegador:** la aplicación escribe los registros y la cola en IndexedDB, persistente en el perfil y disponible a JavaScript del mismo origen. El almacenamiento no se cifra por la aplicación ni se borra al cerrar la pestaña.
3. **Service Worker y Cache API:** `public/sw.js` controla solicitudes del mismo origen. Las navegaciones usan Network First, los recursos estáticos Cache First, el manifiesto Stale While Revalidate y las solicitudes no-GET Network Only. Las otras solicitudes GET del mismo origen, incluida `/api/inspections`, pasan por Network First y una respuesta exitosa puede guardarse en runtime cache.
4. **Red y servidor:** la sincronización envía el payload JSON por `POST /api/inspections` con `Idempotency-Key`. La ruta de demostración exige la clave para deduplicar, pero no autentica ni autoriza a quien envía. GET devuelve todos los elementos en memoria. No hay persistencia duradera, control de acceso ni política de retención en esta ruta.
5. **Dependencias y operación:** los paquetes, artefactos de construcción, variables de despliegue, TLS y controles del alojamiento forman límites externos. La configuración inspeccionada no acredita controles de producción ni un inventario automatizado de secretos.

## Riesgo residual y condiciones previas a producción

- **No desplegar la API demostrativa con información real.** La ruta no ofrece autenticación, autorización ni persistencia, y GET expone todos sus registros.
- La persistencia offline aumenta la disponibilidad, pero amplía el tiempo y los lugares donde existen copias. IndexedDB y Cache API no equivalen a almacenamiento cifrado.
- El escape de React reduce XSS en el renderizado actual, pero no reemplaza validación, CSP, revisión de dependencias ni pruebas de seguridad.
- La sincronización confiable no demuestra que la persona esté autorizada ni que el contenido sea legítimo.
- La ausencia de coincidencias en un escaneo acotado no demuestra que no haya secretos. La rotación es necesaria si alguna credencial llegó a un artefacto público.
- Antes de datos reales se requiere revisión de seguridad, privacidad y operación: identidad institucional, autorización, minimización, retención y borrado, HTTPS/TLS, encabezados, monitoreo, respuesta a incidentes, respaldo/recuperación y pruebas de aceptación.
- Para un sujeto obligado mexicano, determinar la jurisdicción, responsable, fundamento y obligaciones de transparencia/protección de datos aplicables a la institución concreta. Estos documentos son análisis técnico académico, no certificación de cumplimiento legal.
